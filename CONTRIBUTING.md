# Contributing

Thank you for contributing to Hlyx Caption. By submitting a contribution, you
represent that you have the right to submit it and agree that the contribution
is provided under the GNU General Public License, version 3 or any later
version, as described in [LICENSE](LICENSE).

Before opening a pull request:

1. Build the affected configuration on Windows x64 when possible.
2. Run `npm ci` and `npm run docs:build` for documentation changes.
3. Keep personal paths, credentials, certificates, game files, and generated
   binaries out of Git.
4. Preserve third-party copyright and license notices.
5. Describe compatibility, configuration, and security effects clearly.

Do not submit Ultralight SDK files or other proprietary assets unless their
redistribution rights have been verified and documented in
`THIRD_PARTY_NOTICES.md`.
